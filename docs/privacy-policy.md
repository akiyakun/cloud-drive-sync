# プライバシーポリシー（CloudDrive-Sync）

制定日: 2026-10-12

CloudDrive-Sync（以下「本ツール」）は、Google ドライブ上の資料を、AI が読みやすい形式（Markdown など）に変換して手元に保存するための、**開発者本人が個人で使うツール**です。本ツールが扱う情報について説明します。

## 取得する情報

- 利用者の Google ドライブにあるファイルの内容と、その情報（名前・種類・更新日時など）。
  - 同期処理は**読み取り専用**の権限（`drive.readonly`）で取得します。
  - 開発用のテストデータ作成スクリプトは、本ツール自身が作ったファイルだけを扱える権限（`drive.file`）を使います。

## 使い道

取得した情報は、利用者自身の端末や NAS 上で、AI が読みやすい形式に変換して保存するためだけに使います。

## 保存場所と送信先

- 変換した結果と同期の記録は、**利用者自身の端末や NAS にだけ**保存します。
- 開発者や第三者のサーバーには送信しません（Google API との通信を除きます）。
- 取得した情報を第三者に提供・販売しません。
- 同期処理で Google ドライブ上のファイルを変更・削除・アップロードすることはありません。

## Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使用と、ほかのアプリへの転送は、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)（Limited Use の要件を含む）に従います。

## アクセスの取り消しとデータの削除

- 本ツールへのアクセスは、Google アカウントの「[サードパーティ製のアプリとサービス](https://myaccount.google.com/connections)」からいつでも取り消せます。
- 手元に保存した変換結果と同期の記録は、利用者が自由に削除できます。

## 変更

外部の AI サービスへ情報を送る機能（画像の説明文の作成など）を追加する場合など、扱いが変わるときは、このポリシーを更新します。
